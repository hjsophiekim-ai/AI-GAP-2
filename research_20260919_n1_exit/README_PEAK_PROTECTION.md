그 밖에:
1. **임계값 비단조**: PD arm 4.0 의 give 1.0/1.5/2.0 → −20.26 / −15.87 / **+4.14**.
   PF arm 3.5/4.0/5.0 → −57.81 / −24.95 / +0.67. 0.5%p 만 움직여도 부호가 바뀐다.

   악화하지 않는다.
3. 발동이 의미있는 규모(변경 ≥10건)인 후보는 **전부** 한쪽 창에서 악화.
