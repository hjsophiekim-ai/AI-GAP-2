## 2. N1 이 이미 하고 있는 적응

N1 = H50 + `{tp1 3.5, tp2 8.0, tp1_ratio 0, off_tp2 4.0}` + `trail_stop 1.5` + 오후TP 4.0.
`off_tp2` 는 **봉마다** EMA20/EMA50/기울기 구조를 보고 TP2 를 8.0↔4.0 으로 바꾼다 —
즉 사용자가 요청한 "TP2 8 을 열어둘지 3~4 에서 확정할지"의 시장단위 판본이 이미 있다.
그 값어치: 구조판정을 없애면(`off_tp2` 제거) 78일 **−32.41%p**.

그래서 "같은 판정을 포지션 단위로 고정(sticky)"하는 변형은 **정확히 0.00%p** 바뀐다
(`A1_weak_tp2`) — 한 번 구조가 깨진 포지션이 되살아나는 경우가 사실상 없다.
