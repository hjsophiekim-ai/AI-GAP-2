## 2. FLIP-BOX / BREAKOUT 정의 (사후 조정 없음, 전부 causal)

- 플래그 k 시점에 **직전 W분 내 플래그가 M+1개 이상**이면 flip-box 개시.
  (0교차 온셋은 반복 억제 규칙 때문에 항상 R↔B 교대 -> 전환수 = 플래그수-1)
- box = 첫 플래그봉 ~ 마지막 플래그봉 구간 3분봉의 high/low. `range_pct=(hi-lo)/mid`
- 새 플래그가 더 붙으면 box 확장 + 마지막 방향 갱신 (**미래정보 없음**)
- BREAKOUT = 마지막 플래그 방향으로 **완성 3분봉 종가가 box 밖 마감**
  - B1 = 종가 이탈 / B2 = B1 + MACD hist 같은 방향 확대 / B3 = B2 + 다음 3분봉도 box 밖
- 만료: 마지막 플래그 +60분, 또는 15:18봉
- 가상체결: breakout 봉 종료 **다음 1분봉 종가** (즉 breakout 확인 후 첫 체결가능 시점)
- 성과: 하이닉스(방향정규화) + **실제 매매대상 ETF**(RED=0193T0 long, BLUE=0197X0 inverse) 양쪽

민감도 그리드: W ∈ {12,15,18,21} x M ∈ {2,3} x 경계 {포함, 배타} = 16설정. **최적값 선택 안 함.**
