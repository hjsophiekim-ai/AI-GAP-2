### BORDERLINE 인 이유

**올리는 근거**: hard gate 의 구조적 결함(대체 진입) 완전 제거 · PF 가 **세 창 모두**
개선(30일조차 2.439→2.489) · MDD 개선 또는 불변 · 78일 bootstrap 96.5% ·
Top1/3/5 제거해도 uplift 유지 · 새 threshold 없음.

**막는 근거**: 30일 세 배수 전부 음수(boot 18~19%) · 78일 이득이 사실상 OOS 창
한 곳 · **완전 선형이라 방어 가능한 배수가 없다**(최적점이 ×0.00 = hard gate 인데
그건 이미 실패 확인) · **핵심 위험인 weak runner 가 78일에 1건(2.3%)뿐**이라
진짜 발생률을 모른다. 30일은 우연히 그 1건을 포함했고 그것만으로 부호가 뒤집혔다.

### 핵심 — AUC 는 유지되는데 손익 부호는 안 유지된다

**weak 거래 평균 net 이 30일 +0.553% vs OOS48 −1.391%.** feature 의 *순위
판별력*(MFE≥1.5% 구분)은 두 창에서 유지되지만, *실현손익 부호*는 유지되지 않는다.
MFE 가 낮아도 돈은 벌 수 있다 — 30일 weak 17건이 그랬다.
