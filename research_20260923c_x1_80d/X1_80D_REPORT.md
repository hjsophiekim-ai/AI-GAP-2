# B. 아직 shadow 단계 — X1-1 / X1-4 잠재 성능

**A와 절대 합치지 말 것.** production에 진입경로가 없어 손익을 합산하지 않았다.
아래는 "그 시점에 들어갔다면 가격이 어떻게 갔나"일 뿐, 실제 청산 로직을 통과한 수치가 아니다.

MFE60 +2.27% / MAE60 **−2.91%**. BASE가 이미 잡은 신호 **35/68**.

즉 X1-1의 판별력 자체는 방향이 맞다. 그리고 그중 절반(35건)을 BASE가 실제로 진입했으므로
**차단형으로 쓰면 손실을 줄일 여지가 있다.** 다만 9분 내 재승인이 한 번도 성립하지 않아
사양의 "WATCH 후 재승인" 경로는 현재 임계에서 사실상 죽은 코드다.
