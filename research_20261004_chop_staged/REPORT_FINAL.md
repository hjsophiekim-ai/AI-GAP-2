## 최종 판정: **USE E (EARLY-UP-FAST + RS 상위20% ×1.25, 한도 안에서만)**

질문은 "수익은 UP-FAST 수준, 안정성은 EARLY-PASS 수준"이었습니다.
**전제가 틀렸습니다** — C(UP-FAST)가 이미 B(EARLY-PASS)보다 모든 안정성 지표에서 우위입니다.
진짜 문제는 안정성이 아니라 **C의 우위가 하루짜리였다는 것**이고, E는 그 문제를 고칩니다.

## 1. 규칙 (E)

```
C(EARLY-UP-FAST) 그대로:
  UP  : (trigger 까지 dist <= 0.3%) AND c2 AND c3 -> 즉시진입
  DOWN: (dist <= 0.2%) AND c2 AND c3             -> 즉시진입
  미달이면 최대 15분 돌파대기, 미도달이면 폐기 (c2/c3 폐기조건 불변)
추가:
  RS = z(atr60) - z(min_open) + z(xc30) 가 과거일 기준 80퍼센타일 이상이면
  해당 진입 수량 x1.25 (실효 1.3125)
  단, 일 3,000만원 잔여분 안에서만 올리고 증액분은 누계에 즉시 반영
```

RS 통계(mu/sd/thr)는 **그 날 이전 데이터만** 사용(expanding window, 과거 진입 30건 이상, 06/18부터 유효).
미래 데이터 없음. threshold 추가 탐색 없음(기존 ×1.25 / 80퍼센타일 그대로).

## 9. 판정 근거

**USE E.**

1. **A 대비 +1,184,616 (보존율 106.9%)** 이면서 MDD −8.80 → **−6.36**,
   최대1일손실 −834,516 → **−433,778(−48%)**, 손실일 25 → **18**, PF 2.68 → **3.55**.
2. 요청하신 "안정성"은 B 가 아니라 **C/E 가 더 좋습니다** — B 는 MDD −8.33, 손실일 19 로
   세 후보 중 가장 나쁘고 총손익도 A 에 집니다(−291,431).
   **B 를 안정성 기준으로 삼을 근거가 없습니다.**
3. **단일거래 의존도가 실질적으로 낮아졌습니다** — C 는 상위 1일 제외에서 뒤집히지만
   E 는 **상위 3일까지 버팁니다**. 부트스트랩 P(>A) 82.4%.
4. 일일 3,000만원 한도 **초과 0일**, 증액이 한도에 걸린 건 0건.
5. 폐기조건(c2/c3) 불변 → **c2=False 폐기건은 전부 계속 폐기**(10/02 09:54 포함).

### 반드시 같이 보셔야 할 것

- **9월은 여전히 A 에 −522,081 집니다.** RS 가 9월에 4번 걸렸지만 3건이 손실 거래라
  증액이 오히려 손실을 키웠습니다. 9월 약점은 미해결입니다.
- **RS 증액은 손실도 1.3125배로 키웁니다.** 85일 중 5건에서 −151,674 가 추가로 발생했습니다.
  표본 14건은 작고, 9승 5패는 통계적으로 59% 승률과 구분되지 않습니다.
- **85일 전부 인샘플**입니다. RS 임계는 과거일만 쓰는 expanding window 라 미래정보는 없지만,
  ×1.25 / 80퍼센타일이라는 값 자체는 이전 연구에서 고른 것이고 별도 홀드아웃이 없습니다.
- **DOWN 이 C 와 완전동일하지 않습니다** — UP 즉시진입과 RS 증액이 예산·슬롯을 바꿔
  같은 날 뒤 DOWN 거래 수량에 간접 영향이 생깁니다(일일 예산 제약의 직접 결과).
- **EARLY-PASS 는 production 에 구현이 없습니다.** 따라서 replay↔production 거래단위 parity 는
  대조 대상이 존재하지 않습니다. 증명된 것은 "하네스가 A 를 바이트 동일하게 재현한다" 까지입니다.
- 미결 production 이슈: `_execute_scheduled_entry` / `_execute_premarket_carry_entry` 는
  `execute_signal(budget=state.budget)` 를 배수·잔여확인·`note_entry` 없이 호출해
  일일 한도를 **소비하지도 준수하지도 않습니다**. 채택 전 확인 필요.
