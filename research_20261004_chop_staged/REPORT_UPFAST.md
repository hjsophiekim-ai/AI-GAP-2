## 1. C 규칙 (해석2, 지시대로)

```
기존 EARLY-PASS 그대로. DOWN 은 한 글자도 바꾸지 않는다.
UP 만 즉시진입 거리기준을 0.2% -> 0.3% 로 완화한다.
  UP  : (dist <= 0.3%) AND c2 AND c3  -> 즉시진입
  DOWN: (dist <= 0.2%) AND c2 AND c3  -> 즉시진입 (기존과 동일)
c2(확정봉 동방향·중립) / c3(gap 확대) 는 양쪽 다 그대로 요구 -> 폐기조건 불변.
미달이면 기존처럼 최대 15분 돌파대기, 미도달이면 폐기.
```

## 7. DOWN 동일성 — **완전동일은 아닙니다**

| | 건수 | 손익 |
|---|---|---|
| B DOWN | 79 | +10,774,536 |
| C DOWN | 78 | +10,768,509 |

규칙은 DOWN 을 전혀 건드리지 않지만, **UP 즉시진입이 슬롯·예산·포지션 상태를 바꿔 DOWN 에
간접 영향**이 생깁니다. 차이는 **08/10 하루**에 집중됩니다.

```
08/10  B: 11:17 DN 772주 -100,964 / 12:30 DN 1,156주 +403,674 / 14:45 DN 797주 -116,211
       C: 10:54 UP 1,356주 -190,593 / 11:17 DN 927주 -121,235 / 12:30 DN 864주 +301,707
```

C 가 10:54 에 UP 을 즉시 진입하면서 그날 예산 3,000만원 중 상당분을 먼저 쓰고, 이후 DOWN
두 건의 수량이 바뀌었으며(772→927, 1,156→864) 14:45 DOWN 은 예산이 남지 않아 아예 사라졌습니다.
**이 하루가 C−B −196,620 으로 8건 중 유일한 큰 손실**입니다.

이것은 버그가 아니라 **일일 예산 제약의 직접적 결과**입니다 — "청산 후 당일 재사용 금지"가
실제로 작동하고 있다는 증거이기도 합니다.

  08/10 하루에서 −196,620 이 발생했습니다. "DOWN 불변"을 엄격히 요구하신다면
  이 결과는 그 조건을 **충족하지 못합니다**.
