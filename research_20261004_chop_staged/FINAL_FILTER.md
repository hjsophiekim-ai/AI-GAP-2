READ-ONLY. production·config·UI 무수정. 아래 수치는 전부 **기존 85영업일 REAL replay 실측**이며
새로 돌린 재생은 없습니다.

## 0. 결론 먼저

**"같은 자리에서 왔다갔다 하는 장을 사전에 식별해서 안 들어간다"는 9가지 방법으로 측정했고
총손익 기준으로는 전부 음수였습니다.** 그런데 목표를 **최대손실 축소**로 두면 답이 달라집니다 —
**BREAKOUT15** 가 최악일을 절반으로 줄이고, 위험조정수익(복리/MDD)에서 현행을 이깁니다.

제안: **RS125 (수익) + BREAKOUT15 (위험)** 조합. 단, 이 조합은 **아직 재생 검증 전**입니다.

## 3. 제안 필터

```
① 진입 확인 (BREAKOUT15)
   T+3 승인까지는 production 과 동일.
   승인 즉시 매수하지 않고 (플래그봉, T+3 확정봉) 두 봉의
     UP_RED  -> 최고가
     DOWN_BLUE -> 최저가
   를 trigger 로 설정(buffer 0틱).
   승인 후 15분 안에 기초자산 호가가 trigger 를 돌파/터치하면 그 시점에 진입.
   미도달이면 그 signal 폐기(소급진입 없음).
   보유 반대 포지션 청산은 production 그대로 즉시.
   승인 시점에 슬롯을 소비하지 않음 — 실제 체결 때만 소비.

② 사이징 (RS125)
   RS = z(atr60) - z(min_open) + z(xc30)
   RS 상위20%(직전 영업일까지의 확장창 분위수) -> budget_multiplier x1.25
   하향 배수 없음. 차단 없음.

③ 그 외 P3/B3/Q2/Y3/H50/C1/청산/reconcile/EOD 전부 production 그대로.
```

**왜 이 조합인가**: 두 규칙이 서로 다른 축에 작용하고 충돌하지 않습니다.
①은 **진입 여부**(위험 축), ②는 **체결된 진입의 비중**(수익 축)입니다.
①이 자르는 것은 주로 손실 거래였고(전면 적용 시 취소 52건 중 **47건이 손실**, −6,240,844원 회피),
②가 키우는 것은 러너입니다(발동 16건 중 **5건이 TP1+TP2 완주**, 평균 수익거래 +471,858원).

## 4. 반드시 알고 결정하셔야 할 것

- **총손익은 줄어듭니다.** BREAKOUT15 단독이 −1,955,092 이고, RS125 를 얹어도 전액 회복되지 않습니다.
  "최대손실 축소"와 "총손익 증가"는 이 표본에서 **동시에 달성되지 않습니다.**
- 수익만 원하시면 **RS125 단독**이 답입니다 — +885,850 에 MDD·최대1일손실 **무변화**.
- 최대손실 축소가 우선이면 **BREAKOUT15 + RS125** 입니다.
- 둘 다 조금씩 원하시면 **RS125 + SLOT3 ×0.5** 가 중간입니다
  (수익 +885,850 − 35,372, 최대1일손실 −43,567 개선). 다만 효과가 작습니다.
