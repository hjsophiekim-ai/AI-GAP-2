# 사전등록: 부분체결 재호가 추격폭 0.3 / 0.5 / 0.8% 비교 (2026-10-23 작성, 데이터 열람 전)

## 원칙
- 데이터(부분체결 사례, 이후 가격경로)를 보기 **전에** 이 문서를 고정한다. 결과를 본 뒤 기준·후보값·표본 정의를 바꾸지 않는다.
- 후보는 0.3 / 0.5 / 0.8% 세 개뿐이다. 중간값 탐색, 사례별 조정은 하지 않는다.
- 10/23 12:33 한 건(+0.8% 상승)은 표본에 **포함하되**, 판정은 이 건을 뺀 결과로도 같아야 한다.
- 현행값 0.3%가 기본값이다. 아래 채택 조건을 모두 만족하지 못하면 0.3%를 유지한다.

## 표본
- 실계좌 MACD2 신규진입 **매수 지정가 주문**. 원천은 KIS 일별주문체결(TTTC8001R): 주문수량, 체결수량, 주문시각, 주문가.
- 기간: 조회 가능한 전 기간(최소 2026-09-01~). 기간은 열람 전에 정하고 결과를 보고 줄이지 않는다.
- 부분체결 = 0 < 체결 < 주문. 0체결은 별도 집계한다(주 분석에는 넣지 않는다).
- 매도(청산) 주문, 수동 주문, 재주문은 제외한다.

## 측정 (사례마다)
1. P0 = 최초 주문가, t0 = 주문시각.
2. t0+3초 / +5초 / +10초 시점 매도1호가(없으면 체결가) 대비 P0 변화율(%).
   - 초 단위 원천: WS shadow logger(R2) ETF 호가·체결. 없으면 1분봉으로 근사하고 **'근사'로 표시하며, 근사 사례는 판정에서 따로 보고한다**.
3. 원주문 추가체결 가능성: t0 이후 같은 주문의 추가 체결 여부(체결내역 시각) 또는 가격이 P0 이하로 되돌아온 여부.
4. 캡 c마다:
   - 재호가 발생 = t0+3초 매도호가 ≤ floor_tick(P0×(1+c)).
   - 재호가 시 잔량 진입가 = 그 매도호가. 잔량 청산은 **실제 그 거래의 청산 규칙·청산시각 경로**(CHOP ±1.5 등 당시 설정)로 계산한다.
   - 지표: 잔량 손익(원, 수수료 포함), TP 도달 여부, SL 도달 여부.

## 판정 규칙 (고정)
캡 c(0.5, 0.8)를 0.3% 대신 채택하려면 **모두** 만족해야 한다.
1. 재호가 대상 사례 n ≥ 10 (부족하면 INSUFFICIENT → 0.3 유지).
2. 잔량 손익 합계: c > 0.3%이고 차이 > 0.
3. Leave-one-out: 가장 이익이 큰 사례 1건을 빼도 차이 > 0.
4. 10/23 12:33 건을 빼도 2·3이 성립.
5. 잔량 기준 TP 도달률이 0.3% 대비 낮아지지 않음(추격 진입이 TP 근처 고점 매수가 되지 않는지).
6. 최악 1건 손실이 0.3% 대비 1.5배 이상 커지지 않음.
여러 c가 통과하면 **작은 값**을 고른다. 결과는 PROMISING(모의 선행) / NOT USEFUL / INSUFFICIENT 중 하나로만 보고한다.

## 하지 않는 것
- 결과를 보고 대기시간(3초)·fill threshold(70%)·TP 근접폭을 바꾸지 않는다(별도 연구로 다시 사전등록).
- production 값 변경 없음. 판정이 PROMISING이어도 모의 end-to-end 뒤에만 다시 보고한다.
