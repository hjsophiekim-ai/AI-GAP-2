floor{0.0,0.3,0.5,0.8,1.0,1.2} × 확인봉{1,2} × 해제{없음,MFE≥2%,MFE≥3%,MFE3|추세,추세만}

**1.5% 찍고 floor 까지 눌린 뒤 4~6% 로 가는 게 예외가 아니라 표준 패턴.**

### 2-3. 재사용할 발견 — runner 보호를 MFE 임계로 설계하면 안 된다

측정 한계: entry gate 는 removal-only(엔진 재실행 불가 → 슬롯이 비어 생겼을

## 연구 4 — +1.5% 도달 시 부분익절 PT15-X (`g15`,`g16`) → **REJECT**

가설: 도달 시 전량청산이 아니라 **일부만** 익절하면 짧은 랠리는 지키고 runner 는
보존되는가. 잔량에 새 stop/floor 를 추가하지 않고 기존 N1+C1 청산을 100% 그대로 사용.

### 계산 방식 — 해석적 계산이 엔진 재실행과 동일한 근거
* 비용 전부 수량비례 + 최소수수료 0 + ETF 세금 0 => `net_pct` 는 수량무관
* TP/SL/트레일/ETP/H50/C1 판정은 **가격** 기준 => 잔량의 청산 시각·가격·사유가 불변
* 따라서 `P/L = tp_qty x entry x net_TP15/100 + rem_qty x entry x net_base/100` 가 정확
* 사이징 되먹임(첫거래 STOP_LOSS -> x1.20)은 **최종 leg 의 exit_reason** 이 정하는데
  부분익절은 그것을 바꾸지 않는다. 청산자금 당일 재사용 없음.
* 체결 = 도달 봉의 **종가**(낙관적 터치 아님). 정수주 반올림.

78일 158거래 중 +1.5% 도달 **93건(58.9%)**. (30일 43 / OOS48 50)
