## 결론 — **PROMISING** (ADOPT 아님)

채택조건 20개 중 **17 통과 / 1 실패 / 1 부분**. 실패한 것은 **placebo 93.54%**
(기준 95%, 5,000회, ±0.68, 단측 p=0.065). 부분은 **plateau**로, 오전 slot3 축은
고원이 맞지만 front 축은 단조증가라 1.05 라는 지점을 데이터가 지목하지 않는다.

## 새로 확인한 것 4가지

### 1. 요청된 하루 3,000만원 예산은 **이미 production 계약**이다

```
config.DEFAULT_BUDGET                   = 10,000,000
config.X2LITE_SIZING_DAILY_EXPOSURE_CAP = 3.00
                                        -> 하루 원금한도 30,000,000
```

`position_sizing.py` 가 *"exposure 는 진입 시점 누적이다 — 부분익절이나 청산이
누적을 되돌리지 않는다"* 라고 명시하고 코드도 그렇다. 즉 **당일 신규진입 누적 원금
기준**이고 가용현금 재사용이 아니다. 현행 A 도 이미 **12건**을 잘라내고 있다.

### 2. 공표 P2 는 **오후 slot3 에도 ×1.05 를 준다**

연구 원안 람다는 `MIN if (s==3 and ss==MORNING) else 1.05` — "오후 slot3 기존 배수"
라는 서술과 달리 오후 slot3 도 front 와 같이 올린다.

| | 78d Δ복리 | 78d Δ KRW |
|---|---|---|
| 연구원안 P2 (오후s3 1.05) | +54.39 | +1,021,718 |
| 사용자정의 P2 (오후s3 1.00) | +51.98 | +980,543 |

이 번들의 1차 정의는 **오후 slot3 = 1.00** 이다.

### 3. uplift 의 **74.7% 는 배분이 아니라 레버리지**

| 변형 | 78d Δ KRW | 예산사용률 |
|---|---|---|
| ① 배분만 (오전s3 0.25, front 1.00) | +249,178 | 64.9% (−2.3%p) |
| ② 레버리지만 (front 1.05, slot3 무변경) | +732,570 | 69.0% (+1.7%p) |
| ③ P2 = ①+② | +980,543 | 66.9% (−0.3%p) |

상호작용 −1,205 로 사실상 가법적이다. **slot3 를 전혀 건드리지 않고 front 만 올려도
이득의 3/4 이 나온다.** 다만 ① 은 **예산을 덜 쓰면서** 버는 성분이라 레버리지로
설명되지 않는다 — 그것이 이 연구의 진짜 발견이다.

### 4. front 증액이 **오후 slot3(좋은 버킷)의 예산을 잘라먹는다**

cap 발동이 A 12건 -> P2 18건으로 늘고, 그 대부분이 오후 slot3 다. 오후 slot3 기여는
P2 에서 **−75,303 KRW 악화**된다. 예: 20260610 12:39 (+4.45%) 가 A 8.0M -> P2 6.9M
로 잘려 49,143원을 잃는다.

**주문금액이 경로를 바꾸지 않는다는 것을 코드로 증명했다**: `trading_cost_engine` 의
수수료·세금·청산·슬리피지가 전부 quantity 비례이고 `min_commission_krw = 0` 이라
net_pct 는 주문수량과 무관하다. `hengine5` 에서 `w1a`/`exposure` 는 어떤 진입·청산
판정에도 들어가지 않는다. 그래서 사이징 변형은 기준 원장에서 **해석적으로 정확히**
계산되며, 실제 엔진 런과 0건 불일치로 교차검증했다.

## 권고

1. **두 손잡이를 분리할 것.** 연구 결과는 P0(front 1.00)이고, 그것만으로
   예산을 2.3%p 덜 쓰면서 +249,178 KRW / PF 2.766 / MDD −2.76(개선) /
   cap 발동 12->6건이다. front ×1.05 는 별개 안건이다.
2. **오전 slot3 표본 8건 한계는 그대로.** placebo 93.5% 는 "방향은 맞는데 아직
   증명이 부족하다"는 뜻이다. 1~2개월 추가 관측 필요.
3. **후속 조사거리(미검증)**: 아낀 예산을 오후 slot3 로 돌리면 A 와 동일한 67.2%
   사용률에서 **+1,163,819 KRW** 로 P2 를 앞선다. 새 파라미터이므로 배터리를 처음부터
   다시 돌려야 한다.
