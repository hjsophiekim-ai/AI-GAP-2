# 2026-09-11 플래그 시각 불일치 — 결측 1분봉 처리방식 A/B/C/D 격리 비교 (read-only 연구)

## 왜 이 조사를 했나

사용자가 2026-09-11 KIS 차트의 실제 플래그 10개(플래그 **시작시각** 기준)를 확정해 줬다.
`data/validation/macd2/kis_expected_flags.csv` 의 `20260911` 행이 그 ground truth다.

    08:42 RED / 09:00 BLUE / 09:06 RED / 10:24 BLUE / 10:30 RED
    11:33 BLUE / 12:39 RED / 14:00 BLUE / 14:42 RED / 15:15 BLUE

현행 파이프라인(= A)은 이 10개 중 **6개만 정확히 일치**한다. 원인을 분리하기 위해
**결측 1분봉 처리 방식 한 가지만** 바꿔 4안을 비교했다. MACD/T+3/TW TEG/quality/
slot/propagation 로직은 한 줄도 건드리지 않았다.

## 1차 원인: 단일가 구간의 결측 1분봉 -> 3분봉 탈락

체결이 없는 분(장전 단일가 08:50~08:59, 종가 단일가 15:20~15:39)에는 KIS 가 1분봉을
주지 않는다. 조사한 5개 거래일 전부 **동일하게 결측 30분 / 3분봉 3개 탈락(08:48, 15:18,
15:39)** 이었다 — 특정일 사고가 아니라 매일 반복되는 구조다.

그 결과 3분 확정봉 시퀀스가 이렇게 끊긴다:

    1분봉  ... 08:47 08:48 08:49 [08:50~08:59 없음] 09:00 09:01 ...
    3분봉  08:39 08:42 08:45 ──────────────────────> 09:00 09:03
                            (08:48 은 2/3분만 있어 filter_complete_3m_bars 가 폐기,
                             08:51/08:54/08:57 은 애초에 생성되지 않음)

MACD 는 **시퀀스 재귀**이므로 EMA 는 "15분 경과"를 "3분 경과"로 취급하고, 그 오차가
이후 전 구간에 남는다. 같은 이유로 15:15 다음 봉이 15:42 다.

## 비교한 4안 (결측 처리만 다름)

| | 방식 |
|---|---|
| **A** | 현행 — `filter_complete_3m_bars`: 3분 중 1분이라도 없으면 그 3분봉 폐기 |
| **B** | 부분 3분봉 유지 (필터 미적용) |
| **C** | 결측분을 당일 범위 내 close ffill 로 채운 뒤 resample |
| **D** | A 의 봉 집합 + 시간간격 보정 EMA (alpha_eff = 1-(1-a)^dt, dt=실제경과분/3), 일자 경계는 dt=1 로 끊음 |
| **D2** | D 와 같으나 일자 경계도 시간보정 (참고용) |

공통: 프레임 = 직전거래일 1분봉 + 대상일 1분봉(NXT, market_div=NX),
`resample_completed_3m`, MACD(12,26,9) `adjust=False`,
zero-cross + 동일방향 dedup (`signal_engine.evaluate_macd_crossover` 규칙 그대로).

채점: truth 플래그마다 같은 방향 탐지 플래그를 **±2봉(6분) 안에서 1:1 최근접 매칭**.
채점구간은 truth [최초, 최종] ± 6분(매칭 허용오차와 동일 — 경계 truth 의 밀림이
"구간 밖"으로 빠져 미탐으로 오집계되는 것을 막는다).

## 결론 — 채택 후보는 B 하나, 단 "완전 일치"에는 못 미친다

* **C / D / D2 는 탈락.** 9/11 과탐을 0으로 줄이지만 **8/20 golden(12/12)과 7/31(4/4)을
  깨뜨린다.** 9/11 한 날만 보면 매력적이던 ffill 이 실제로는 회귀다.
* **B 만 회귀 없음** (8/20 12/12 유지, 7/31 4/4 유지, 8/03 불변) **+ 9/11 개선**
  (정확 6->7, 완전미탐 1->0). 4일 합계 정확 28->29.
* 그러나 **어떤 방식도 9/11 을 10/10 정확일치로 만들지 못한다.** B 도 7 정확 + 3 한봉밀림
  이고 11:54/11:57 마이크로크로스 과탐 2건이 남는다.

남은 불일치는 결측 처리로 설명되지 않는다. 9/11 09:00 BLUE 지점의 gap 은 **+15.39**,
당일 |gap| 중앙값(794)의 **1.9%** 다. 부호가 이 정도로 간신히 결정되는 봉은 어떤
결측 정책으로도 맞출 수 없고, KIS 와 동일한 EMA 상태가 필요하다. 그런데
`kis_client.get_minute_candles_for_date(period_min=...)` 의 `period_min` 은 실제 요청에
쓰이지 않는 죽은 인자라 **KIS 네이티브 3분봉을 받아올 방법이 현재 코드에 없다**.

### B 를 채택하기 전에 반드시 결정해야 할 것

B 는 `filter_complete_3m_bars` 를 무력화하는 것이고, 그 함수는 docs §4 의
"API 오류/누락 페이지가 실제 3분봉으로 위장하는 것을 막는다"는 요구사항 그 자체다.
B 는 **정상적인 무거래 분(단일가)과 데이터 유실을 구분하지 못한다.** 따라서 그대로
채택하면 안 되고, 더 좁힌 변형(B′: 결측이 알려진 무거래 구간 08:50~09:00 / 15:20~15:30
안에 있을 때만 부분봉을 살린다)을 별도 판단해야 한다. **이 조사에서는 코드 변경 없음.**
